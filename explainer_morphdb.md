## Product Name & One-Line Description

## Problem Solved (2-3 sentences)

Database migrations are traditionally manual, error-prone, and time-consuming. MorphDB solves this by using AI to automatically translate SQL between different dialects (SQL Server → Snowflake, Oracle → PostgreSQL, etc.) while preserving business logic, reducing migration time from weeks to minutes.

## Key Features

- 🤖 **AI-Powered Translation** - Uses OpenAI GPT-4o-mini and Anthropic Claude for intelligent SQL translation
- 📦 **Batch Processing** - Upload multiple SQL files for bulk translation
